# M3. Communication Styles and Adaptability · Participant eWorkbook

Static web package for participants. No server code, database, or build step. It contains no speaker notes, answer slides, or sample responses.

## Host it
1. Upload this whole folder as-is to an HTTPS location participants can reach (public, or behind your learner sign-in). Keep the folder structure; all paths are relative.
2. Share these two addresses with the instructor; they go in the welcome chat message:
   - eWorkbook link: the address of `index.html`
   - PDF backup link: the address of `downloads/M3_eWorkbook_PDF_backup.pdf`
3. MIME types: `.webp` → `image/webp`, `.pdf` → `application/pdf`.

## How it works
- Participants type notes beside each slide and complete Parts 1–6. Work saves in their own browser (localStorage) and is never sent anywhere.
- Participants can download a backup file, restore it, export their notes and responses as an HTML page, or print to PDF. Copy buttons put responses on their own clipboard for the meeting chat.
- No external requests, cookies, or tracking.

Supported browsers: current Microsoft Edge, Google Chrome, Safari, and Firefox, on laptops and tablets.
